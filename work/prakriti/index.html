How it works

Retrieve

Qdrant combines lexical and semantic retrieval. Exact species names and questions phrased in ordinary language can both contribute candidates.

Rank

Reciprocal rank fusion combines result rankings before generation. This introduces a retrieval stage that can be inspected separately.

Cite

The documented citation gate checks the response after generation. Source coverage still depends on the indexed collection.
