How it works

Capture

A browser on the local network triggers the camera through Flask. Keeping controls in the browser lets a phone operate the device.

Encode

Still images can upload directly. Video passes through FFmpeg so the result plays on phones and desktops.

Archive

Rclone transfers the file to OneDrive. The documented cleanup step waits for a successful upload before reclaiming local space.
